- JavaScript is the object oriented programming language
- It contains OOP concepts like **Inheritance, Polymorphism, Abstraction,** and **Encapsulation**
- **Inheritance:** Sub-class extends Super-class
    - Used for code reusability
- **[[4 - Polymorphism|Polymorphism]]:** One entity showing different behaviours at different time
- **[[2 - Abstraction|Abstraction]]:** Hiding the implementation details and showing only certain methods
- **[[3 - Encapsulation|Encapsulation]]:** Writing the variables and related methods inside the Object
