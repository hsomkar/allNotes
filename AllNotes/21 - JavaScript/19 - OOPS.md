- JavaScript is the object oriented programming language
- It contains OOP concepts like **Inheritance, Polymorphism, Abstraction,** and **Encapsulation**
- **Inheritance:** Sub-class extends Super-class
    - Used for code reusability
- **[[4 - Polymorphism|4 - Polymorphism]]:** One entity showing different behaviours at different time
- **[[2 - Abstraction|2 - Abstraction]]:** Hiding the implementation details and showing only certain methods
- **[[3 - Encapsulation|3 - Encapsulation]]:** Writing the variables and related methods inside the Object
